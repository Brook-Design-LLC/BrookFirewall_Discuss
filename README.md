# BrookFirewall_Discuss

Issue templates and automated log analysis for BrookFirewall support.

## Offline browser tools

GitHub issue uploads are limited to **10 MB per file**. Use these tools locally in your browser before submitting an issue:

| Tool | URL |
|------|-----|
| Compress media | https://brook-design-llc.github.io/BrookFirewall_Discuss/media-compress.html |
| Split large logs | https://brook-design-llc.github.io/BrookFirewall_Discuss/log-split.html |

Split log parts (`*.txt.part1`, `*.txt.part2`, …) can be uploaded together to the Manual Log Upload form; the workflow merges and analyzes them automatically.
