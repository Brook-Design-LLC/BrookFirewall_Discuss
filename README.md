# BrookFirewall_Discuss

Issue templates and automated log analysis for BrookFirewall support.

GitHub issue uploads are limited to **10 MB per file**. Use [Brook Media Compressor](https://github.com/Brook-Design-LLC/BrookMediaCompressor) to compress media before uploading.

## MITM Lua script documentation

BrookFirewall ships a Lua 5.4 runtime for MITM scripts (HTTP request/response hooks). Author-facing API reference lives under [`app/doc/`](app/doc/).
